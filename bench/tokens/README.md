# Token benchmark

Measures how many tokens the same data costs as JSON (indented and minified),
YAML, TOON, and AXS Grammar v3. Full numbers are in [RESULTS.md](RESULTS.md).

## Method

- **Data**: five synthetic datasets shaped like typical MCP tool results,
  generated by `generate.py` with fixed seeds and committed in `data/`:
  GitHub-style issues (nested objects, multiline bodies), a file listing and
  SQL rows (uniform tables), search results (table with long text), and a
  nested service config (deep objects, few arrays). Values are synthetic, so
  the absolute numbers are illustrative; shapes are what matter.
- **Encoders**: JSON via Python `json` (`indent=2` and minified separators),
  YAML via PyYAML `safe_dump` (insertion order), TOON via
  `@toon-format/toon` 4.4.0 with default options, AXS via `axs from-json`
  (the canonical serializer). AXS and TOON outputs are decoded again and must
  equal the input, so no format wins by losing data.
- **Tokenizers**: tiktoken `o200k_base` (GPT-4o and later) and `cl100k_base`
  (GPT-4), and the Llama 3 tokenizer (`Xenova/llama3-tokenizer-new`). Claude's
  tokenizer is not public; counting it needs the `count_tokens` API and an
  API key, which this benchmark does not use yet.

## Running

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm install
cargo build
python3 generate.py
.venv/bin/python run.py
```

`run.py` uses `target/debug/axs` unless `AXS_BIN` points elsewhere, and
rewrites `RESULTS.md`.

## Findings (2026-11-04, AXS at commit 0e64716)

Totals for o200k_base (fewer is better; percentages vs minified JSON):

| JSON (indent 2) | JSON (minified) | YAML | TOON | AXS |
|---:|---:|---:|---:|---:|
| 24,393 | 16,464 | 19,549 (+18.7%) | 14,110 (−14.3%) | 15,403 (−6.4%) |

cl100k_base and Llama 3 give the same picture within 0.3%; on this ASCII
data the Llama 3 counts matched cl100k_base exactly.

1. **Tables are where the savings are.** On uniform rows AXS saves 12–20% vs
   minified JSON (file listing −11.9%, SQL rows −19.8%), TOON 23–29%.
2. **On nested data every indentation format loses to minified JSON.** GitHub
   issues: AXS +17.8%, TOON +14.1%, YAML +17.1%; nested config: AXS +25.8%,
   TOON +20.9%. Indentation and line breaks cost more than JSON's braces when
   most values are not tabular.
3. **The gap to TOON is canonical formatting, not the grammar.** Re-encoding
   the same AXS trees with a model of the serializer:

   | AXS canonical form variant | Total tokens |
   |---|---:|
   | current: `a, b` and `- ` before table rows | 15,370 |
   | `a,b` without spaces | ~14,500 |
   | `a,b` and table rows without `- ` | 14,135 |
   | plus short primitive objects inline: `user: {login: ivan, id: 1}` | 14,028 |
   | TOON 4.4.0 for reference | 14,110 |

   The space after commas costs ~900 tokens and the row dash ~330. Text blocks
   cost ~33 tokens more than quoted strings with `\n`, which is negligible.

These variants were measured with a throwaway re-encoder, not the Rust
serializer; adopting any of them is a grammar/serializer decision.
